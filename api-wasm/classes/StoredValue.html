    Class StoredValue

    Wasm/native wrapper around [casper_types::StoredValue].

    Typed as_* covers the common query variants. Auction/message variants (Bid, BidKind, Withdraw, Unbonding, MessageTopic, Message, Prepayment) expose variant and toJson only.
